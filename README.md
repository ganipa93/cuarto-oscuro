# Cuarto Oscuro

Test de ideología política argentina: 44 afirmaciones, 4 ejes (economía, valores, mundo, orden) y 25 partidos nacionales.
Muestra cercanía de ideas con cada partido, campañas y dichos de sus referentes, votaciones del Congreso (actas nominales del Senado y prensa para Diputados) y proyectos presentados, con fuentes enlazadas.

No es una recomendación de voto. Es un sitio estático (`index.html`), sin dependencias ni backend; las respuestas no se guardan.
